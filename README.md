# 网页版我的世界 · Minecraft Web

用纯前端（Three.js + 自研体素引擎）复刻 **Minecraft Java Edition 1.20.1** 的观感与操作，并把几个「老牌/热门模组」做进去了。

> 粉丝自制作品，与 Mojang / Microsoft 无关，不包含任何官方素材。所有贴图都是 Canvas 程序化生成的 16×16 像素图。

## 玩法

- 打开网页 → 「单人游戏」→ 新建世界（可设名称、种子、模式：生存 / 创造，类型：默认 / 超平坦 / 大型生物群系）
- 世界自动保存在浏览器 localStorage，随时「保存并退回到标题画面」

### 操作（键鼠）

| 操作 | 按键 |
| --- | --- |
| 移动 | W A S D |
| 跳跃 / 疾跑 | 空格 / 按住 Shift |
| 破坏 / 放置 | 左键长按 / 右键 |
| 物品栏 / 交互 | E |
| 快捷栏 | 1–9、滚轮 |
| 视角 | 鼠标（点击画面锁定指针） |
| 调试信息 | F3 |
| 第三人称 | F5 |
| 全屏 | F11 |
| 丢弃物品 | Q |

创造模式里双击 W 可开始飞行，再按一次空格升降。手机端有虚拟摇杆和按钮。

## 已实现的内容

- 地形：生物群系（草原 / 森林 / 沙漠 / 雪原 / 海洋）、洞穴、矿脉、树木、花草、水面、岩浆
- 方块：40+ 种（草方块、石头、矿石、原木、树叶、玻璃、水、岩浆、火把、工作台、熔炉、箱子、黑曜石、下界岩、萤石…）
- 玩法：挖掘 / 放置、工具耐久与挖掘等级、掉落物、合成（2×2 与 3×3 工作台）、熔炼、箱子、饥饿与生命、溺水与岩浆伤害、死亡重生
- 下界：黑曜石 + 打火石开传送门，坐标 1:8 换算
- 界面：标题画面（全景背景 + 像素 LOGO）、世界列表缩略图、创建世界、选项（FOV / 渲染距离 / GUI 缩放 / 灵敏度 / 难度…）、控制说明、暂停、死亡、加载进度

## 模组（内建）

- **等价交换 Equivalent Exchange**：转化桌、EMC 学习与买卖、哲学之石、暗物质 / 红物质及对应工具
- **JEI 物品管理器**：物品栏右侧的物品清单，点击查看配方
- **小地图**：右上角实时地形与朝向

## 文件说明

- `index.html`：页面入口（three.js 从 CDN 加载）
- `game0.b64` ~ `game3.b64`：游戏代码，gzip + base64 分段存放，运行时解压执行
- 需要完全离线、单文件版本，可以自行用源码目录重新打包

> 注意：因为要从 CDN 加载 three.js，第一次打开需要联网；想离线玩请使用单文件版（three.js 已内联）。
